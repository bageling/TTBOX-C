画面中心取多大的一块送去识别（单位像素，正方形）。调大看得更广、远处的人也能看到，但人在画面里变小、识别更容易漏；调小只看正中间一小块，看得更清楚，但边上的人看不到。一般 320 起步。
准星会在这个圆圈范围内自动跟人，出了圈就不跟。瞄准范围就是**截取尺寸**那块方形画面里能画出的最大圆（内接圆），1.00 = 用满这个圆；调小就是按比例把圆收小（比如 0.5 = 只有一半大）。
正数 = 识别区域往右挪，负数 = 往左挪（像素）。画面中心偏了才需要动它。
正数 = 往下挪，负数 = 往上挪（像素）。
准星最终停在哪：正数 = 往人右边偏一点，负数 = 往左（像素）。想瞄头就往上调下面那格。
正数 = 往下偏（比如瞄胸口），负数 = 往上偏（比如瞄头）。
识别出来的东西要有几分把握才当它算人。调高 = 更少误判（不会把箱子当人），但远处模糊的人可能漏掉；调低 = 更容易抓到人，但容易乱瞄。
同一个人经常被框出好几个框，重叠超过这个比例就把多余框去掉。调高 = 只合并几乎完全重合的框（可能一个人留几个框）；调低 = 稍微挨着就合并（靠得很近的两个人可能被当成一个）。
