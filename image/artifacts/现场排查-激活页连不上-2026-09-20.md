# 现场排查：激活页连不上服务器

现象：烧录后开机，面板能打开，第一个页面（激活页 `/activate`）连不上服务器。
状态：**未定位**，需要现场取一组数据。

## 一、先说清楚：这是流程事故

交付流程原本是「WSL 全量自检 → 交付烧录步骤 → **业主实测**」。
实际执行时，WSL 自检全绿后就直接写回镜像并报了"交付完成"，**真机这一道根本没走**。
自检覆盖的是"产品树/服务/姿态"，覆盖不了"真机上能不能连到云端"——所以全绿仍然翻车。

## 二、已知的好消息（排除项）

| 项 | 证据 |
|---|---|
| 云端服务是否在活 | ✅ 从开发机探测 `POST https://cctv2.top:10046/ttbox/api/client/card-login`，返回 `401 {"error":"missing_signature_headers"}` —— 路由在、TLS 通 |
| 镜像里的云端凭据 | ✅ `/opt/ttbox/config/default.json` 存在，`root:ttbox 0640`，ttbox 可读 |
| 网络栈 enable 态 | ✅ `systemd-networkd` / `systemd-resolved` / `networkd-wait-online` 都已 enable，无 NetworkManager 抢 |
| netplan | ✅ `/etc/netplan/01-ttbox.yaml`，匹配 `en*` 与 `eth*`，dhcp4，`optional: true` |
| 设备指纹（机器码） | ✅ RK3588 的 `/proc/cpuinfo` Serial 有值（开发板实测 `9ecf266dc8154491`），激活不缺机器码 |
| `/run/ttbox` 开机创建 | ✅ core 单元有 `RuntimeDirectory=ttbox`；usbproxy 有 `RuntimeDirectory=ttbox-mouse-passthrough` |
| 缺模型会不会让 core 起不来 | 大概率不会：`ModelAdapter::analyze` 只在加载模型时校验输入输出，缺模型应是"推理不可用"而非进程退出 |

## 三、要现场取的数据（控制台登录 root/root，整段粘）

```bash
{ echo "== 时间 =="; date; echo "== IP =="; ip -4 a | grep inet; echo "== DNS =="; cat /etc/resolv.conf; echo "== 解析 =="; getent hosts cctv2.top || echo 解析失败; echo "== 连授权服务器 =="; curl -s -o /dev/null -w "HTTP=%{http_code}\n" -m 12 -X POST https://cctv2.top:10046/ttbox/api/client/card-login -H 'Content-Type: application/json' -d '{}'; echo "== 服务 =="; systemctl is-active ttbox-core ttbox-web; echo "== 激活态 =="; curl -s -m 5 http://127.0.0.1:8000/api/license | head -c 300; }
```

判读：

| 输出 | 说明 |
|---|---|
| `date` 年份不对 | **时钟没同步** ⇒ HTTPS 证书校验必失败（RK3588 无 RTC）。先 `systemctl restart systemd-timesyncd` |
| IP 为空 | 没拿到 DHCP：查网线、查 `networkctl status`、`journalctl -u systemd-networkd` |
| 解析失败 | DNS 有问题：`cat /etc/resolv.conf` 看是不是 `127.0.0.53`（resolved 在跑才有效） |
| 连授权服务器 HTTP=000 | 出口被墙 / 没路由。`curl` 加 `-v` 看在哪一步断 |
| 服务不是 active | `journalctl -u ttbox-core -n 50` 看为什么 |
| `/api/license` 里 `activated:false` 且 core 不可达 | core 没起来，激活写不回去 |

## 四、临时开 SSH（让我远程查）

镜像出厂把 SSH mask 了，现场开回来三条命令：

```bash
sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
grep -q '^PermitRootLogin' /etc/ssh/sshd_config || echo 'PermitRootLogin yes' >> /etc/ssh/sshd_config
rm -f /etc/systemd/system/ssh.service /etc/systemd/system/ssh.socket && systemctl daemon-reload && systemctl enable --now ssh && ip -4 a | grep inet
```

查完关回去：

```bash
systemctl disable --now ssh
ln -sfn /dev/null /etc/systemd/system/ssh.service
ln -sfn /dev/null /etc/systemd/system/ssh.socket
systemctl daemon-reload
```
