## 一、接线

```text
被控电脑（游戏机/PC）
   │  HDMI 线（电脑的 HDMI 输出 → 盒子 HDMI 输入）
   ▼
TTBOX 盒子
   │  USB 线（盒子的 USB 口 → 电脑的 USB 口，盒子在电脑眼里是一个鼠标）
   ▼
被控电脑
```

| 线 | 方向 | 作用 |
|---|---|---|
| HDMI | 电脑 → 盒子 | 盒子的眼睛：只看电脑画面 |
| USB | 盒子 → 电脑 | 盒子的手：模拟真实鼠标移动 |
| 网线 | 路由器 → 盒子 | 开面板、激活、升级 |
| 电源 | — | 用原装电源，供电不足会导致采集掉线 |

盒子不读内存、不改游戏数据，电脑上**不需要装任何软件**。

## 二、刷机

1. 准备一张 **8GB 以上** 的 TF 卡，或直接写盒子的 eMMC。
2. 用烧录工具把 `ubuntu-22.04-preinstalled-server-arm64-orangepi-5-plus-V5.img`
   原样写到目标存储上（推荐 `balenaEtcher`；命令行用 `dd`）。
3. **写之前一定确认目标盘对不对**（TF 卡 / eMMC 的盘符）。
   > ⚠️ **写错盘会不可逆地毁掉那个盘上的数据**，且不在服务范围内。
4. 写完后把卡插回盒子（或断开 eMMC 写入模式），上电。

刷机过程中不要断电；中途断电可能让设备起不来，需要返修。

---

## 三、开机与找 IP

1. 通电开机。首次启动会比平时慢一点（要生成机器 ID、做一次开机自检）。
2. 找盒子的 IP，两种方法任选：
   - **控制台**：接显示器 + 键盘（或串口），用随附的出厂口令登录 `root`，跑 `ip a`，
     看 `en*` 或 `eth*` 那行的地址。
   - **路由器**：进路由器后台看 DHCP 客户端列表，找新出现的有线设备。
3. 记住这个 IP，后面都用 `http://<IP>:8000`。

---

## 四、打开面板

浏览器打开：

```text
http://192.168.x.x:8000
```

第一次打开会自动跳到**激活页**（`/activate`）——因为还没激活，其它页面会拦住。

面板是网页，手机、平板、电脑浏览器都能开；不用装 App。

## 五、激活（要联网，一分钟）

**前置条件**：客户网络的防火墙要放行 `cctv2.top` 的 **10086** 端口（HTTPS）。
拿不准就先在客户网络里用浏览器试一下能打开 `https://cctv2.top:10086/ttbox`。
**内网隔离、或者断网的环境，在线激活一定失败**，那种情况要用离线卡（下面第二种）。

**方式 A · 在线卡密（主用）**
1. 激活页输入框里填卡密，提交。
2. 成功后页面自动进面板，状态显示已激活、到期时间、可绑设备数。
3. 之后盒子每 60 秒向云端报一次心跳。**断网不会立刻锁死**，但卡到期或被云端禁用会掉回未激活。

**方式 B · 离线卡（无外网环境用）**
把整段离线卡内容（一整坨以 `{` 开头的 JSON）**原样粘进同一个输入框**提交。
盒子用内置公钥验签，不联网。

**激活失败的常见原因**

| 提示 / 现象 | 原因 |
|---|---|
| 打不开、超时 | 客户网络没放行 `cctv2.top:10086`，或盒子根本没网 |
| 卡密无效 / 已被使用 | 卡本身问题，找发卡方 |
| 设备数超限 | 这盒子的机器码已被别的卡占满，先解绑 |
| 提示"云端凭据未配置" | 镜像问题（不该出现），联系厂家 |

## 六、模型（出厂已带一个，可直接用）

出厂镜像里**已经内置一个 EP 模型并已选中**，开机就能识别。想换成自己的模型，两种方式：

**方式 A · 面板上传（推荐）**
模型库页 → 上传/导入 → 选中刚导入的模型。

**方式 B · 手工放文件**
把模型放到这个目录（每个模型一个子目录）：

```text
/var/lib/ttbox/models/installed/<模型ID>/
├── model.json      ← 模型描述，必填
└── model.rknn      ← 模型本体
```

`model.json` 最少要有这些字段：

```json
{
  "id": "my-model",
  "name": "我的模型",
  "format": "rknn",
  "version": "1.0.0",
  "input_width": 320,
  "input_height": 320
}
```

- `id` 只能用小写字母、数字、`._-`，最长 64 字符
- `format` 目前只支持 `rknn`
- `version` 必须是 `x.y.z` 三段

放完后**到模型库页选中它**（不要手工改配置里的 `model_id`，面板切模型才算数）。

## 七、鼠标怎么才动（两件事，别混）

### (1) 物理鼠标直通 —— 不需要按任何热键

盒子上插一个 USB 鼠标，电脑那边就会多出一个鼠标，鼠标怎么动、电脑光标就怎么动。
这一段**不看总开关、不看注入开关、不看热键**。

> ⚠️ 但「完整透传」模式下，**盒子上必须插着 USB 鼠标**，`usb-proxy` 才会启动。
> 盒子上没插鼠标，盒子不会向电脑假装成鼠标，电脑那边就什么都看不到（这是最常见的"鼠标不能动"）。
> 手上没有额外鼠标，就在面板上切**「合成模式」**：盒子上不插鼠标也能用。切换会重启 `usb-proxy`，电脑会重新枚举一次设备。

### (2) AI 自动修正 —— 要开开关 + 按热键

出厂为了安全，**总输出和鼠标注入都是关的**（`output_enabled=false`、`mouse.enabled=false`）。要手动开：

1. 面板 → 鼠标相关页 → 打开**"启用鼠标输出"**（总开关）
2. 打开**鼠标注入**
3. 设**瞄准热键**。⚠️ **热键是鼠标按键**（下拉里可选项：左键 / 右键 / 中键 / 两个侧键），**不是键盘按键**。
   按住这个鼠标键，AI 的修正才会送进电脑；松开立即停。
4. 按住热键，有框时鼠标会被拉住 / 微调

> 不按住热键，盒子不会主动动客户的鼠标 —— 这是刻意设计。
>
> 说明：配置文件里那个 `aim_keys_text: KEY_LEFTSHIFT,KEY_RIGHTSHIFT` 是历史遗留字段，
> **运行时不读它**，按 Shift 不会有任何效果。以面板下拉框里选的鼠标键为准。

## 八、确认画面进来了

面板**预览**页能直接看盒子看到的画面（走 8001 端口）。

| 现象 | 说明 |
|---|---|
| 采集 FPS > 0 | HDMI 信号进来了 |
| 预览有画面 | 画面链路通 |
| 有检测框、检测数量 > 0 | 模型在认目标 |
| 预览黑屏、FPS = 0 | HDMI 没进来：换线、确认电脑有把画面输出到盒子、重新插一次 |

## 九、常用调参

| 想调什么 | 去哪 |
|---|---|
| 截取尺寸 / AI 视野范围 | 主页「截取尺寸」（与推理 ROI 同一块，改小看得更窄但更快） |
| 识别阈值 `conf` / 重叠抑制 `nms` | 参数页；默认 0.25 / 0.45 |
| 瞄准手感（PID、过冲、贝塞尔曲线） | 鼠标/瞄准参数页 |
| 存一套自己的参数 | **预设**页保存，之后一键切 |
| 灵敏度曲线 | 运动训练页 |

调完记得在**预设**页保存一份，恢复出厂或升级后能一键拿回来。

## 十、出问题先看这四步

```text
1. 预览黑屏？  → HDMI 没进盒子（换线 / 确认电脑输出 / 重插）
2. 有画面没框？→ 模型没选中（去模型库页选中 EP 或你自己的模型）
3. 有框，鼠标不动？→ 先分清哪一段：
      · 物理鼠标插在盒子上，电脑光标也完全不动 → 链路问题：
          盒子上到底插了 USB 鼠标没有 / 线是不是插在盒子的设备口（盒子→电脑）/ 切「合成模式」试
      · 物理鼠标能动、只有 AI 不修正 → 三件事都要满足：
          总输出开了 + 鼠标注入开了 + 瞄准热键**用鼠标键**按住（按键盘 Shift 没用）
4. 面板打不开？→ 盒子通电了吗？IP 变了吗（路由器重新看一眼）？
```

在控制台（显示器或串口，用随附口令登录 `root`）还能查：

```bash
systemctl is-active ttbox-core ttbox-web ttbox-preview ttbox-usbproxy ttbox-edid
# 期望全是 active；哪个不是，重启它：systemctl restart <名字>

journalctl -u ttbox-core -n 100     # 看 core 的日志
ip a                                 # 看 IP 还在不在
```

盒子**自带自愈巡检**（`ttbox-ensure.timer`）：服务掉了会自动拉回来，所以偶发重启不用担心。

## 十一、升级

面板**升级**页 → 检查更新 → 升级。走 OTA 通道 `https://cctv2.top:10086/ota`，需要联网。

按之前的定案：**升级完成后流水线是停止状态**，需要在面板点启动才会跑起来。

## 十二、安全与维护边界

- 日常维护用显示器/串口的 `root`；**远程排障由售后处理**，客户不需要自行登录远程。
- 出厂口令请首次登录后立即更换：控制台上执行 `passwd` 即可。
- 盒子里所有东西都在 `/opt/ttbox` 和 `/var/lib/ttbox` 下，不动系统其它部分。
- 它只"看画面 + 动鼠标"，不改游戏文件、不读写内存。
- 刷机写错盘、刷机中途断电造成的损失不在服务范围内。
