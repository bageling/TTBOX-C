## 2. PID 实现（`:573-592`）

### 2.1 基础 PID（增量式）
```lua
pid.error = reference - feedback
pout = pid.error * kp
dout = (pid.error - pid.lastError) * kd
integral += pid.error * ki         -- clamp 到 ±maxIntegral
output = pout + integral + dout     -- clamp 到 ±maxOutput
```
参数：`pid_kp=0.30, pid_ki=0.001, pid_kd=0.3`，`maxIntegral=100`，`maxOutput=pid_speed_limit_value=10`。

### 2.2 串级 PID（`createCascadePID`，`:583-584`）
```lua
PID_CascadeCalc(cp, oR, oF, iF)
  PID_Calc(cp.outer, oR, oF)              -- 外环：位置
  PID_Calc(cp.inner, cp.outer.output, iF) -- 内环：速度
  cp.output = cp.inner.output
```

### 2.3 四种算法可切换（`cfg.mobile_algorithm`）
`0` 线性 / `1` 串级PID / `2` 抗过冲PID / `3` ADRC / `4` 贝塞尔。

## 3. ★ 四个「按框尺寸/速度自适应」机制（TTBOX 完全没有）

这是本次分析**最有价值的发现**——它们是纯视觉方案近似解决 3D 透视问题的手段。

### 3.1 动态自瞄范围：按框**面积**线性插值（`:4576-4582`）
```lua
local function calculateDynamicRangeValue(box_w, box_h)
    local area = (box_w or 0) * (box_h or 0)
    local minRange = cfg.dynamic_aim_range_min      -- 40
    local globalRange = cfg.user_aim_range_x       -- 100
    if area <= cfg.dynamic_aim_range_box_min then return minRange end        -- 200 px²
    elseif area >= cfg.dynamic_aim_range_box_max then return globalRange end -- 1200 px²
    else return minRange + (globalRange - minRange) *
        ((area - box_min) / (box_max - box_min)) end  -- 中间线性插值
end
```
**含义**：远处小目标（面积<200）用**小范围**（40px，只瞄很准的），
近处大目标（面积>1200）用**全范围**（100px）。
⇒ **框面积 = 距离的代理量**，用它来缩放选靶范围。

### 3.2 动态滤波：按框面积分段线性（`:1806-1817`）
```lua
local area = box_w * box_h
if area <= filter_box_mid then
    ratio = min_ratio + (1 - min_ratio) * (area / box_mid)   -- 小目标：强滤波
    return filter_base * ratio
else
    ratio = 1 + (max_ratio - 1) * ((area - box_mid) / (box_mid * 2))
    return filter_base * min(ratio, max_ratio)               -- 大目标：弱滤波
end
```
⇒ **小目标抖动大 → 强滤波；大目标抖动小 → 弱滤波**。

### 3.3 速度自适应 Kp（`:1759-1775`）
```lua
avgSpeedPerFrame = totalDist / #history      -- 最近 N 帧平均位移
if avgSpeedPerFrame >= speed_adaptive_kp_threshold then
    return speed_adaptive_kp_move_mult        -- 动得快 → 提高增益
else
    return speed_adaptive_kp_static_mult      -- 静止 → 降低增益
end
```
⇒ **高速目标需要更大增益**（否则跟不上），静止目标需要小增益（否则抖）。

### 3.4 头身稳定过滤（`:839-859`）
同帧出现 (bodyN + headN) ⇒ **删掉 headN**，只留身体框。
理由：头框会把落点抢到头上。仅当 body+head **同时存在**时才删（单独出现不动）。

## 4. 抗过冲（`:1722-1756`）

双层距离门 + 帧数门 + 冷却：
```lua
if dtt > anti_overshoot_outer_distance then      -- 太远：不动，且启动冷却计时
    ... return mx, my
end
if dtt <= inner_distance and inner_count < inner_frames then
    mx = mx * (1 - inner_strength/100)          -- 近距离：衰减输出
    inner_count = inner_count + 1
end
if dtt <= outer_distance and outer_count < outer_frames then
    mx = mx * (1 - outer_strength/100)          -- 中距离：轻度衰减
end
-- 两个计数器都满 ⇒ cycle_done，本轮不再衰减（避免持续削弱）
```
另有 `out_of_range` 超时冷却（`:1725-1729`）：远距离持续超阈值则 `resetAntiOvershoot()`。

## 5. 选靶：优先级打分 + 锁定状态机

### 5.1 打分公式（`:794-801`）
```lua
distScore = 1 / (1 + distance/100)
sizeScore = min(1, box_w*box_h/10000)
stick     = distLast < switch_threshold ? (1 - distLast/threshold)*stickiness : 0
rawPriority = distScore*weight_dist + sizeScore*weight_size + stick*0.5
```
> ★ **注意**：`sizeScore` 用 `面积/10000`，在 640 窗口下 2 倍镜起就撞顶（17086≫10000）⇒ 相当于没配。
> **TTBOX 已在 V3 阶段 4 修过这个问题**（改为 `sqrt(面积)/size_ref`）——我们比它更进一步。

### 5.2 范围判定（`:804`）
```lua
candidateOK = |dx| < effective_aim_range_x and |dy| < effective_aim_range_y
```
纯像素矩形，无圆形/FOV。

### 5.3 锁定状态机（`:4585-4599` + `:896-917`）
- `switch_delay` 内且距上帧锁定点 < `same_target_distance` ⇒ 判为同一目标，清丢失计时。
- `lock_hold_time` 内维持锁定，只刷新位置。
- **迟滞**（`:906-909`）：`best.priority < curPriority*(1+hysteresis)` ⇒ 放弃换靶。
- **冷却**（`:912-917`）：换靶后 `switch_cooldown` 内且**类别不同** ⇒ 不换。

### 5.4 距离排序 bug（`:889`）
```lua
if best then ... return {best.x, best.y, ..., best.distance*best.distance, ...}
```
⇒ 返回的是**距离平方**，而 `:885` 返回的是 `math.sqrt(dx*dx+dy*dy)`（距离）。
**两处返回的 distance 量纲不一致**，且调用方按距离用 ⇒ 最近目标可能选错。
（TTBOX 无此问题。）

## 7. 压枪（`:1103-1115`）
三段预设查表 + 正弦漂移 + 一阶平滑：
```lua
segIdx = min(3, floor(el/(totalTime/3))+1)        -- 三段
v = seg.vert * global_vert;  h = seg.horiz * global_horiz
if drift_enabled: h += sin(2π*t*freq) * amplitude  -- 横向漂移（模拟真人）
smooth: h = h*(1-s) + last_h*s                      -- 平滑
```
门控：`hasT and dist<=limit` 或 `recoil_no_target_always`。
> **TTBOX V1.0.40 已重做为 yu 式速率模型**（`3×strength×speed×ramp×dt`），比这个三段查表更简洁。

## 8. 提前量 lead2（`:1820-1858`）
带**Y 轴抑制**：`|lastMoveY|` 超过阈值 ⇒ 提前量归零（防止纵向抖动被放大）。

## 9. 自动调参 auto_tuning（`:4725-4748`）★ 对标定方案最有价值

```lua
local absError = sqrt(ex*ex + ey*ey)
local sign = (ex > 0) and 1 or ((ex < 0) and -1 or 0)
-- 过冲：误差符号变号
if last_error_sign ~= 0 and sign ~= 0 and sign ~= last_error_sign then
    overshoot_count = overshoot_count + 1
end
-- 响应时间：首次锁定 → |err| < 10px
if not response_recorded and absError < 10 then response_time = now - first_lock_time end
-- 峰值误差

-- 稳定时间：|err| < 5px
```

## 11. 结论与建议（一次给全，不再零散）

**架构层面**：BB-828 与我们**同构**（像素域闭环）。它的价值不在"角度域"，而在
**四个「按框尺寸/速度自适应」的机制**——这是纯视觉方案能做的"物理补偿"。

**建议按此优先级改「算」链路**：

1. **框面积 → 选靶范围**（`:4576`）
   我们 `search_radius_px` 是固定值；改成按目标框面积在 `[min, 全范围]` 间插值。
   效果：远处小目标只锁很准的（避免选到边缘歪框），近处大目标放开。

2. **框面积 → 死区/跳变门控缩放**（`:1806` + hex-port 版 `calcAdaptiveDeadband`）
   我们 `kMeasJumpAbsPx=8.0` / `clip_center_max_px=105.0` 是固定像素。
   改成 `8.0 × (ref_h / cur_h)` 之类 ⇒ 远近手感一致。

3. **速度 → Kp 双档**（`:1759`）
   目标帧间位移超过阈值 ⇒ 增益 ×1.x；静止 ⇒ ×0.x。抑制"静止时抖、移动时跟不上"。

4. **Y 轴提前量抑制**（`:1830`）
   若我们启用 `continuous_lead`，加 Y 抑制防纵向放大。

5. **标定**（`:4725` 判据 + 二分搜索）
   用 BB 的过冲/稳定时间判据，接进二分，自动化换游戏调 kp。

★ 1~3 都是**低成本、高收益**（各改几行），且不需要新参数入库（阈值可先写死）。
