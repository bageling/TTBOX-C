## 二、链路诊断三条根因（全部实测）

### 根因 A（★ 最深）：PID 没有 dt 参数
`Pid1Controller::update(double error)`（`Pid1Controller.hpp:92`）签名无dt；
同链路 AimTracker / RecoilController / PersonalTrajectoryShader **全吃 dt** ⇒ 只有 PID 裸奔。
**实测**：帧距 6.94→41.67ms（丢 5 帧）⇒ **D 项放大 6 倍**，严格线性无归一化。

### 根因 B：板端退化成纯 P+D，永不过冲
实测（`predict_x=0`）：符号翻转 **0 次**，单调收敛 ⇒ 不像人。`predict=1` 时翻转 2 次。
**预测项才是「像人」的来源，被默认配置掐死。**

### 根因 C：PID 无输出饱和 ⇒「越打越慢」
累积控制量 ∝ 误差 ⇒ 偏得越多收得越慢。**两条独立路径同结论。**

★ **救命通道**：`K_p`/`K_d` 不经过 predict ⇒ 参数配错 100 倍也不彻底失控。

## 三、★ 两个矛盾（须业主裁决）

### 矛盾 1：「pid 完全移植」与它带进来的默认值自相矛盾
`MouseTypes.hpp:383-385` 记的移植参数是 `predict=3.0`，而记忆里早记着 predict 自激增益≈`1/(1−0.667·predict)` ⇒ **3.0 必然发散**；
**板端实测 `predict_x=0`**，与移植文档矛盾。

### 矛盾 2：p 重置 —— 三方都漏掉的缺陷
`reset()` 清 `velocity_filter_p`/`integral_filter_p` 为 0（构造是 1.0）⇒ **每次 reset 后前馈增益=0、静默失效**。
**但 pid1 原文（`test_pid1.cpp:82-95`）也清 p** ⇒ 改它破「完全移植」铁律 + 破对拍。

## 四、待业主拍板（收敛到 1 件）

### ★ 唯一需裁决：p 重置的 `0.0 → 1.0`（一个 token）

```cpp
// Pid1Controller.hpp:227-229  构造默认
velocity_filter_p = 1.0;      // "初始状态是 1.0"
integral_filter_p  = 1.0;
// Pid1Controller.hpp:143-145  reset
velocity_filter_p = 0.0;      // "初始状态是 0.0"   ← 与构造矛盾
integral_filter_p  = 0.0;
```
★ **`reset()` 的语义是「回到初始状态」，而初始状态被明确定义为 1.0；reset 却设 0.0。**
⇒ 这**不是设计分歧，是内部自相矛盾**（比「上游有缺陷」这种口味之争容易批准）。
⇒ 后果：Kalman 增益 k=0.0099 ⇒ `velocity_filter_x` 爬不过 0.5 阈值门 ⇒ **K_i恒 0 ⇒ predict 前馈失效**。
⚠ **严重度前提（chain-timing 第三轮更正）**：139ms 是**慢速目标单点样本**；快速目标（`error_diff`大）只需~4ms。
上报时必须带这个前提，否则会高估。

### 原四件决策的收敛结果

| # | 原决策 | 现状 |
|---|---|---|
| 1 | 面板 Fitts 残留 | **仍需拍板**（删文案，零风险） |
| 2 | `offset_y` 默认 0.5→0.31 | **仍需拍板**（命中"走近跑到头上"） |
| 3 | `predict` 基准（3.0 会爆 vs 实跑 0） | **降级为待实测**（见下） |
| 4 | p 重置 | **收敛为唯一裁决项**（一个 token） |

★ **T1（PID 加 dt）从「确证必改」降级为「机制成立、影响待实测」**——chain-timing 承认自己没测过丢帧率，
把「机制存在」当成了「后果严重」。是否修取决于**帧距直方图实测**。

### ★ 关键先例：改 PID 可以零破对拍

`test_pid1.cpp:246-255` 记载 **V1.0.39 已经改过 PID**（`+last_u` → `+last_u*gain_`）且保住对拍。
对拍调用**全是单参**（`:187/203/220/235`）⇒ 用默认参数保原文行为即可：
```cpp
double update(double error, double dt_seconds = -1.0);   // 默认 -1 = pid1 原文
```
⇒ **T1 与 T3 不构成「是否偏离完全移植令」的决策，可独立推进，不必等业主。**
