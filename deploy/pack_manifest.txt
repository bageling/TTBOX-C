# TTBOX 出货包白名单 —— 单一真源（S3 / 2026-09-19 交付方案；P1 双列化 2026-10-01）
#
# 谁读这份文件：
#   scripts/ttbox_fhs_init.sh 的 sync_tree（首次装机，装到 /opt/ttbox/releases/<ver>）
#   scripts/ttbox_pack_ota.sh（OTA 出货打包，产出 .ota.tgz + .sign.json）
#   两处读同一份清单、用同一套语义 —— 改这里一处，装机树与 OTA 包一起变。
#
# ── 条目语法（双列：源路径 → 目标路径）────────────────────────────────────────
#   <源路径> -> <目标路径>
#
#   · 两条路径都是【仓库根相对路径】。禁绝对路径、禁含 ".."、禁含空白。
#   · 源路径可以是：目录 / 单个文件 / 末段带通配符（如 deploy/systemd/*.service）。
#   · 目标路径写法由源决定，二选一，写错即打包失败（fail-closed）：
#       源不含 "*"  → 目标是【精确落点】，不得以 "/" 结尾。
#                     源是目录 ⇒ 整树落到该目录名（V1.0.52 起已无改名条目，规则保留）
#                     源是文件 ⇒ 该文件落到该路径
#       源含 "*"    → 目标是【目录前缀】，必须以 "/" 结尾；
#                     每个匹配项落到  目标前缀 + 匹配项的文件名（basename）
#   · 源路径 glob 展开为空、或源路径不存在 ⇒ 打包失败（不许静默少装）。
#   · 目录条目整树拷贝时剔除 __pycache__ / *.pyc / .git / tests（与 tcopy 同一剔除集）。
#
# ── 这份清单就是出货树的全部来源 ──────────────────────────────────────────────
#   出货树 = 本清单映射结果 + 两个构建产物（bin/ttbox_core_main、lib/librknnrt.so）。
#   脚本侧【不再做任何增删文件的后处理】，只做权限归一化。
#   ⇒ 要把某个文件挡在包外，唯一办法是让它不出现在任何条目的源里。
#
# ── 不进这份清单的东西（也不许进）────────────────────────────────────────────
#   bin/ttbox_core_main、lib/librknnrt.so —— 构建产物，由脚本按闭集规则从构建目录取
#   docs/ tools/ modules/ tests/ —— 内部文档与工具，绝不出货（定案 H-26 / S1）
#   任何 *.priv.pem / .testkeys —— 私钥绝不上板（板端自检逐条扫）
#
# ── 数据结构口径（冻结，2026-10-01 业主拍定；2026-10-06 V1.0.52 修订）──────────
